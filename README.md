# Cinderlake Provenance Workspace

Internal review workspace and dataset registry for the provenance of the
datasets used by the Cinderlake model family.

## Contents

- `PROVENANCE_POLICY.md` - review policy, approved licenses and entry format.
- Cycle branches carry the audit ledger and manifest for a review cycle.
- The current cycle is reviewed on branch `audit/2026-11`.
- Released dataset payloads and their cards are mirrored under `registry/*` refs.
