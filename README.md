# Cinderlake Glossary v2 (Raw)

Raw data behind our processed Cinderlake-Glossary v2 release, adopted from the
original dataset from LumenLex team.

The data format for each line in the `glossary_entries_v2_4f.tsv` file is
tab-separated:

```
term_id<TAB>surface_form<TAB>gloss<TAB>domain_tag
```
